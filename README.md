# Confidential Computing Lab

A comprehensive research repository documenting experiments, notes, and insights on Confidential Computing technologies and frameworks.

## About

This repository serves as a centralized knowledge base for exploring Confidential Computing across various platforms, including Trusted Execution Environments (TEEs), remote attestation mechanisms, cloud provider implementations, and blockchain integrations.

Confidential Computing protects data in use by performing computation in a hardware-based Trusted Execution Environment. This project aligns with the mission of the [Confidential Computing Consortium](https://confidentialcomputing.io/), which defines and accelerates the adoption of confidential computing technologies.

## About the Confidential Computing Consortium

The [Confidential Computing Consortium](https://confidentialcomputing.io/) brings together hardware vendors, cloud providers, and software developers to accelerate the adoption of Trusted Execution Environment (TEE) technologies and standards. This repository's research contributes to understanding and implementing these emerging technologies.
